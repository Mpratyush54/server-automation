Consent defaults

What happens before a visitor has made a choice. A visitor's own choice always wins.

Delete a person's data

Permanently removes what this project stored about one user or one session. This cannot be undone.

Only a hash is kept, in the audit log, as a record of the request.

Enter a user id, a session id, or both.

What gets deleted
  • Log entries and error events for the user or session (MongoDB).
  • The visitor's consent records.
  • Session replay recordings (object storage, MinIO).
  • Matching log lines in the log store, through Loki delete requests. Loki applies them on its own schedule.
  • An audit entry is always recorded. It keeps the ids and, if given, a hash of the email.
