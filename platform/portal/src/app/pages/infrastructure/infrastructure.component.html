Add a server

Run these two commands in a terminal. The join token stays on your servers and never passes through the browser. Learn more

  1. On an existing server, create a join token 
    sudo platformctl token create --role agent --ttl 2h --output /root/agent.token
  2. Copy the token file to the new server, then run 
    sudo platformctl join --role agent --server https://<server-ip>:6443 --token-file /root/agent.token --nodes <node-ips>

Needs the ha install profile. For an extra control server, use --role server with a server token.
