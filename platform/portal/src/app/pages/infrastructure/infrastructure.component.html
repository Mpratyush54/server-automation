Add a node

Nodes join with platformctl join on a server installed with the ha profile. Join tokens are created on an existing server and never pass through the browser.

  1. On an existing server, create a join token 
    sudo platformctl token create --role agent --ttl 2h --output /root/agent.token
  2. Copy the token file to the new node, then run 
    sudo platformctl join --role agent --server https://<server-ip>:6443 --token-file /root/agent.token --nodes <node-ips>

To add an etcd server instead, use --role server with a server token. See High availability.
