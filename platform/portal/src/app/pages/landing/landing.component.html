Run your apps on your own servers. Keep them running when one fails.

Cairn is a self-hosted platform for your apps. It installs on Ubuntu servers you control and gives you deployments from Git, databases, logs, metrics and traces, off-site backups and high availability, all in one portal. Start on one server, or on three for high availability.

Also included. Running on your servers.

  • Databases for each project

    PostgreSQL, MongoDB and Redis for every environment, each with its own user, so one project cannot read another's data.

    Add a database

  • Alerts and status pages

    Uptime checks, alert rules and on-call escalation to email, Slack, Discord, PagerDuty or a webhook, and a public status page for each project.

    Set up alerts

  • Errors and real users

    Errors grouped into issues across releases. With full monitoring and the browser SDKs, session replay and heatmaps too.

    Track errors

  • Preview environments

    Every push to a branch other than main gets its own temporary deployment and address, for review before merging.

    Preview environments

  • Builds from source

    Turn on builds and Cairn builds your image on your servers, from a Dockerfile or with Cloud Native Buildpacks.

    Build from Git

  • Sign-in, roles and audit

    Two-factor sign-in, per-project roles and an audit log of every change. Servers get a firewall and automatic security updates by default.

    Security details

From one server to many. In five steps.

  1. Install on an Ubuntu serverOne command sets up Kubernetes and the services you pick.sudo platformctl provision
  2. Connect your repositoryChoose a branch for each environment.
  3. Deploy and watch it runPushes deploy automatically; logs, metrics and errors appear on the project.
  4. Add servers for high availabilityJoin two more servers with a server token.sudo platformctl --auto join --role server ...
  5. Restore and rebuildRestore PostgreSQL to a moment in its recovery window, or rebuild a lost server from the encrypted archive.sudo platformctl restore --pitr <time> --confirm
