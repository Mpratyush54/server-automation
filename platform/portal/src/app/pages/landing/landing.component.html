A FEW PRACTICAL QUESTIONS

Before you give it a server.

What is Platform?

Platform is an open-source, self-hosted internal Platform-as-a-Service. It combines a web dashboard, an API, the platformctl CLI, application SDKs, and an MCP server to help you deploy and operate applications on Kubernetes (k3s).

What do I need to install it?

Start with an Ubuntu 22.04 or newer server, sudo access, and at least 8 GB of RAM for the full stack. Check the installation guide for networking, domain, and component requirements before provisioning.

Do I still use Kubernetes and Argo CD?

Yes. Your applications still run on Kubernetes, and Argo CD can sync your GitOps manifests. The dashboard and SDKs bring those workflows together.

Can an AI agent run anything on my server?

Agent access uses tokens with explicit scopes and a command guard. Read-only, mutating, and destructive commands have different policies. Destructive commands require a human JWT and approval. See the MCP tools and policy for the exact rules.

Who runs and pays for the infrastructure?

You run Platform on infrastructure you control and pay your hosting and any external service costs. The source is available on GitHub, so you can inspect the system before installing it.
