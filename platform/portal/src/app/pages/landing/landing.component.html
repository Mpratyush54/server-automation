Run your apps on your own servers. Keep them running when one fails.

Platform installs everything an app needs on Ubuntu servers you control: deployments from Git, databases, backups, monitoring and alerts, in one dashboard. Start on one server, add more for high availability.

Databases included. Restore to the second.

PostgreSQL, MongoDB and Redis for each project, with credentials delivered to your app by the SDKs. On multi-server installs PostgreSQL archives every change to S3-compatible storage, so you can restore to any point in the last 14 days.

Add servers when it matters. Lose one, keep running.

Start on one server. Join two more and the platform spreads apps, databases and storage across them. When a server fails the others take over, and it rejoins on its own when it returns.

From one server to many. In five steps.

  1. Install on an Ubuntu serverOne command sets up Kubernetes and the services you pick.sudo platformctl provision
  2. Connect your Git repositoryLink GitHub or GitLab and choose a branch per environment.
  3. Deploy and watch it runPushes deploy through Argo CD; logs, metrics and errors appear on the project.
  4. Add servers for high availabilityJoin two more servers with a one-time token.sudo platformctl --auto join --role server ...
  5. Recover from anythingRestore a database to a point in time, or rebuild a lost server from backups.sudo platformctl restore --pitr <time> --confirm
